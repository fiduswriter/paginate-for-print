# paginate-for-print Contributions Guide

Whether you're contributing through development, creating examples, finding
bugs or just asking questions - thanks in advance for your help!

## I found a bug!

Please file a bug report on our GitHub issues page:
https://github.com/fiduswriter/paginate-for-print/issues

Issues with an HTML file example and correct / incorrect output PDFs are much
quicker to debug and very appreciated.

## I fixed something!

Open a pull request on GitHub, and explain what you did.

## I need help!

Open an issue on
[GitHub](https://github.com/fiduswriter/paginate-for-print/issues) with any
remarks, questions, or issues you have.
